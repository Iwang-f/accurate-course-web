# Accurate Course Web v2.4 — Indonesia Copy, FAC-Inspired Sections, Mobile Compat

> **Orchestrator pattern:** subagent-driven-development — implementer per task + 2-stage review (spec → quality).
> **Working dir:** `/home/ubuntu/projects/accurate-course-prototype`

**Goal:** Copywriting semua halaman ditulis ulang ke tone semi-santai kredibel Indonesia (sapa "Anda", padat, langsung, anti-kaku). Section layanan + benefit/sertifikat diadopsi dari pola FAC Institute tapi dieksekusi dengan design language kita. Chip hero dihapus. Mobile 360px benar-benar kompatibel (touch target, spacing, tipografi).

**Keputusan user (grill 2026-09-03):**
1. Tone: semi-santai kredibel — padat, langsung, sapa "Anda", hindari kalimat kaku
2. Adopsi dari FAC: section layanan kursus (grid offerings) + benefit eksplisit — "nanti kita sesuaikan"
3. Sertifikat: ADA — dari Accurate Pro Academy (factual, boleh diklaim)
4. Scope copywriting: semua 5 halaman + data di site.ts
5. Eksekusi: plan + subagent per task, 2-stage review
6. Hapus: hero chips "2 hari rekap bulanan / 95% rekonsiliasi beres / 10x laporan lebih cepat"

**Tone rules (spec untuk semua task copywriting):**
- Sapa "Anda", jangan "kamu", jangan "Saudara"
- Kalimat pendek. Maks 20 kata. Satu ide per kalimat.
- Konkret > abstrak: "input jurnal sampai laporan keuangan jadi" bukan "pengoperasian software secara sistematis"
- Boleh pakai istilah sehari-hari akuntan: "balance", "closing", "jurnal", "rekonsiliasi"
- Anti AI-isms: jangan "di era digital ini", "solusi tepat", "optimalisasi secara maksimal", "mempermudah"
- Jangan overclaim: angka statistik placeholder sampai klien konfirmasi
- Perbandingan gaya: ❌ "Program pelatihan disusun berdasarkan alur kerja akuntansi perusahaan" → ✅ "Materinya mengikuti cara kerja akuntan sungguhan: dari input jurnal sampai laporan siap dibaca."
