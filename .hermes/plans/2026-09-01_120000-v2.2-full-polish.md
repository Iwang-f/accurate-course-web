> **Orchestrator:** KIMI K3 — dispatch tasks via delegate_task subagents or direct execution.

## Risks & Tradeoffs

1. **Fraunces bundle size:** ~40KB gzipped. Acceptable for font impact. Can add `font-display: swap` (already configured) to prevent FOIT.
2. **Motion on non-home pages:** Adds ~2KB gzipped via `motion` import. Since it's already in bundle from home page, tree-shaking means no additional cost.
3. **shadcn Select vs native:** shadcn Select renders as a dialog on mobile, which is different UX than native dropdown. Must test thoroughly.
4. **Placeholder OG image:** Simple canvas-generated image works, but client should replace with branded version later.
5. **DESIGN.md as canonical source:** If tokens drift between DESIGN.md and globals.css, the design.md lint will catch it. This is intentional.
